# Contributing

Thank you for contributing to going-haywire. The rules for every repository of the
organisation — roles, the introduction before a first pull request, issues, tools, making
the change, the pull request, review, working with AI agents, and what differs in a library
(`haybale-*`) — are one page of core's docs:
[contributing](https://github.com/going-haywire/haywire/blob/master/docs/collaboration/contributing.md)
([on the docs site](https://going-haywire.github.io/haywire/docs/collaboration/contributing/)).

Working with an AI agent? Tell it: *Set me up for Haywire: read
<https://raw.githubusercontent.com/going-haywire/haywire/master/docs/agents/start.md> and follow
it.*
